# Userscripts

## ChatGPT Chat Score Heatbar
Adds a growing heatbar to ChatGPT chat links based on the local activity score.

[Install](https://raw.githubusercontent.com/opendaniil/browser-tweaks/main/userscripts/chatgpt-chat-score-heatbar.user.js)

## ChatGPT Finish Cue
Plays a short sound and/or flashes the page when ChatGPT finishes responding.

[Install](https://raw.githubusercontent.com/opendaniil/browser-tweaks/main/userscripts/chatgpt-finish-cue.user.js)

## ChatGPT Prompt URL Auto-Send
Auto-clicks Send when ChatGPT URL has `?q=` or `?prompt=`.

[Install](https://raw.githubusercontent.com/opendaniil/browser-tweaks/main/userscripts/chatgpt-prompt-url-auto-send.user.js)

## ChatGPT Read Aloud: Speed, Pause, Auto-Read
Adds compact controls for Read Aloud: speed, play/pause, Space shortcut, and per-chat auto-read.

[Install](https://raw.githubusercontent.com/opendaniil/browser-tweaks/main/userscripts/chatgpt-read-aloud-controls.user.js)

## ChatGPT Dictation Hotkey + Auto-Send
`Alt+D` toggles ChatGPT dictation and can auto-send when the button appears.

[Install](https://raw.githubusercontent.com/opendaniil/browser-tweaks/main/userscripts/chatgpt-dictation-hotkey-autosend.user.js)

## Zen Browser: Compact Mode Shortcut Priority
Prevents websites from handling `Cmd+S` / `Ctrl+S` so Zen Browser can use it for Compact Mode.

[Install](https://raw.githubusercontent.com/opendaniil/browser-tweaks/main/userscripts/zen-browser-compact-mode-shortcut-priority.user.js)
